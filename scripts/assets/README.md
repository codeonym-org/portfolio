## Regenerating

**The Monolith and the shards.** Headless Blender (≥ 4.2). No downloaded
meshes: a convex hull is Voronoi-fractured by cutting it along the bisector
planes of random seeds.

```bash
blender -b -P scripts/assets/monolith.py -- public/models/record
```

`SEED` at the top of the script decides how the body breaks; `PIECES` and
`GAP` how finely and how far apart. The app depends on the node names
(`piece_NN`, `heart`, and one shard per sector id) and on the two material
slots of each piece (`shell`, `fracture`); materials themselves are replaced
at runtime (`src/components/scene/monolith.tsx`, `constellation.tsx`). If
Blender's Python cannot import `numpy` (the glTF exporter needs it), the
script falls back to the distro's `site-packages`.

**The studio light.** Download the 1k HDR from Poly Haven, then shrink,
deepen and tint it (the clamp keeps the lamps from blowing out the bloom):

```bash
magick studio_kontrast_04_1k.hdr -resize 512x256 -evaluate Pow 2.0 -evaluate Multiply 1.1 \
  -fx "min(u,7)" -color-matrix "0.84 0 0 0 0.95 0 0 0 1.15" public/env/studio.hdr
```

**The social card.** With the app running, Playwright (not a project
dependency) opens it at 1200×630, raises every shadow, hides the interface
and sets the title in the site's own fonts:

```bash
URL=http://localhost:3000/ node scripts/assets/social-card.mjs src/app/opengraph-image.png
cp src/app/opengraph-image.png src/app/twitter-image.png
```

## `world-map.mjs`

Turns Natural Earth 1:110m land (public domain) into one SVG path, `src/record/world-map.ts`, for the map card.

```bash
node scripts/assets/world-map.mjs <ne_110m_land.geojson>
```

## `holo-map.mjs`

Builds `public/data/holo-map.json`, the only data the holographic map loads (about 500 kB, 135 kB gzipped):
the world's coastlines, the borders around the base, the base country's outline and the city's main roads.

| Input | Source · license |
| ----- | ---------------- |
| `ne_110m_land.geojson`, `ne_50m_admin_0_countries.geojson`, `ne_10m_admin_0_countries.geojson` | [Natural Earth](https://github.com/nvkelso/natural-earth-vector/tree/master/geojson) · public domain |
| `overpass-roads.json` | OpenStreetMap through the Overpass API, fetched once (the query is in the script's header) · © OpenStreetMap contributors, ODbL |

```bash
node scripts/assets/holo-map.mjs ne_110m_land.geojson ne_50m_admin_0_countries.geojson \
  ne_10m_admin_0_countries.geojson overpass-roads.json
```

The inputs are not in the repository. Roads are cut at 12.5 km from the base (`BASE` and `REACH_KM` in the
script; `BASE` must match `player.base`). To move the map to another city, change `player.base`, the Overpass
box, `BASE` and `HOME`, then run the script again.

**The Erebus models.** Download the GLB (1k textures) of each model in the
table, plus `knight.glb` as built for the old temple (git history,
`scripts/assets/knight.py` at `fcddfb0`), into one folder under the names at
the bottom of `pack-erebus.mjs`, then pack: only the clips the game plays are
kept, textures become 512 px WebP and everything is meshopt-compressed
(2.2 MB in all). The stone textures are the 1k JPGs from Poly Haven,
re-encoded with `magick <in>.jpg -quality 80 <out>.webp` (1.6 MB); the rock's
colour is lifted first (`-gamma 1.55 -modulate 100,75`), it is near black as shipped.

```bash
mkdir <scratch> && cd <scratch> && npm init -y
npm i @gltf-transform/core@4 @gltf-transform/extensions@4 @gltf-transform/functions@4 draco3dgltf meshoptimizer sharp
cp <repo>/scripts/assets/pack-erebus.mjs .
IN_DIR=<downloads> OUT_DIR=<repo>/public/models/erebus node pack-erebus.mjs
```
