# Assets

Everything the scene loads lives under `public/`. The geometry is generated
for this site; the rest is CC0 or supplied by the owner. Credits are in
`world.credits` (`src/config/world.config.ts`) and shown at The Gate.

| Path                                 | What                                                                 | Source · license |
| ------------------------------------ | -------------------------------------------------------------------- | ---------------- |
| `public/models/record/monolith.glb`  | THE SYSTEM's body: a crystal broken into 30 pieces, plus its `heart` | generated by `monolith.py` |
| `public/models/record/shards.glb`    | one crystal per sector of the record, instanced for every entry      | generated by `monolith.py` |
| `public/env/studio.hdr`              | the light the obsidian reflects (512×256, graded violet)             | [Studio Kontrast 04](https://polyhaven.com/a/studio_kontrast_04), Poly Haven · CC0 |
| `src/app/opengraph-image.png`        | the social card: the live scene with the title set over it           | captured by `social-card.mjs` |
| `public/audio/*` (sfx)               | interface sounds, ARISE                                              | [Kenney](https://kenney.nl) interface / sci-fi / RPG packs · CC0 |
| `public/audio/theme.mp3`             | suspense theme loop                                                  | supplied by the owner, re-encoded 128 kbps |
| `public/audio/notify.mp3`            | System notification chime                                            | supplied by the owner, trimmed and re-encoded |

## Regenerating

**The Monolith and the shards.** Headless Blender (≥ 4.2). No downloaded
meshes: a convex hull is Voronoi-fractured by cutting it along the bisector
planes of random seeds.

```bash
blender -b -P scripts/assets/monolith.py -- public/models/record
```

`SEED` at the top of the script decides how the body breaks; `PIECES` and
`GAP` how finely and how far apart. The app depends on the node names
(`piece_NN`, `heart`, and one shard per sector id) and on the two material
slots of each piece (`shell`, `fracture`); materials themselves are replaced
at runtime (`src/components/scene/monolith.tsx`, `constellation.tsx`). If
Blender's Python cannot import `numpy` (the glTF exporter needs it), the
script falls back to the distro's `site-packages`.

**The studio light.** Download the 1k HDR from Poly Haven, then shrink,
deepen and tint it (the clamp keeps the lamps from blowing out the bloom):

```bash
magick studio_kontrast_04_1k.hdr -resize 512x256 -evaluate Pow 2.0 -evaluate Multiply 1.1 \
  -fx "min(u,7)" -color-matrix "0.84 0 0 0 0.95 0 0 0 1.15" public/env/studio.hdr
```

**The social card.** With the app running, Playwright (not a project
dependency) opens it at 1200×630, raises every shadow, hides the interface
and sets the title in the site's own fonts:

```bash
URL=http://localhost:3000/ node scripts/assets/social-card.mjs src/app/opengraph-image.png
cp src/app/opengraph-image.png src/app/twitter-image.png
```

## `world-map.mjs`

Turns Natural Earth 1:110m land (public domain) into one SVG path, `src/record/world-map.ts`, for the map card.

```bash
node scripts/assets/world-map.mjs <ne_110m_land.geojson>
```
