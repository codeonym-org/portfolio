# 005: Four stories; the record is refreshed first

**Date:** 2026-11-12 (grilling, Q5; agreed: "ok" to the recommended option)

**Question:** what are the epic's stories, and in what order?

**Decision:** **four stories, in this order:**

1. **Refresh the record** — drop the academic projects; add the OSS and org projects, the guilds and the new skills.
2. **The first gate (rank C) and the catalog** — routes, `/gates` with sealed cards, a richer but light gate.
3. **Live data for the System** — GitHub read access and a map, as things the agent can summon.
4. **The Deep S-tier gate** — named in the epic, planned later.

- **Why:** the record on the live site is out of date today, it is shared by every gate, and the gate's design
  should be built around the real projects.
- **Not chosen:** one large C-tier story holding everything (nothing ships until much of it is done); gate first,
  record second (the gate would be designed around projects about to be removed).
