# 006: A visitor has one progress, shared by every gate

**Date:** 2026-11-12 (grilling, Q6; agreed: chose "One shared progress (Recommended)")

**Question:** a visitor earns XP, a level, a sync percentage and risen shadows. With several gates, is that
progress shared between them?

**Decision:** **one visitor profile for the whole site**, kept in the browser as today. What is earned in one gate
counts in every gate. Each gate decides how much of it to show.

- **Why:** a visitor who explored the rank C gate does not start from zero in the Deep S-tier gate, and that gate
  can build its rewards on the shared progress.
- **Not chosen:** progress per gate; progress only in the S-tier gate (the rank C gate would drop XP, levels and
  ARISE — the largest change to what exists).
