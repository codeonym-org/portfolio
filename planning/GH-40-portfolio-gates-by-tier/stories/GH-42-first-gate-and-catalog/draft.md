# The first gate (rank C) and the gates catalog

## Problem

The current page is the only way in, and the owner finds it too minimal: most of the interface and 3D elements
are gone. Hiring teams need a fast page that gives information quickly, and there is no place to list gates.

## Change

Build the first named gate, rank C: light on resources, quick to check, information first. Build the catalog at
`/gates` with each gate at `/gates/<gate-name>` and sealed cards for gates not built yet; `/` opens the default
gate (epic decisions 002, 003). The gate reads the shared record and agent (decision 004) and shows guilds.

## Done when

- `/` opens the rank C gate with no choice to make; `/gates` lists it and shows the Deep S-tier gate as sealed.
- A recruiter can find experience, projects by guild, skills, the CV and contact without using the agent.
- The owner confirms the gate no longer feels too minimal.

Design: story decision 001. Tickets, in order: the gates catalog, gate routes and the sealed screen; then a one-minute brief in The Surface.
