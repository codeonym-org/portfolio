# The Deep S-tier gate: full gameplay, extended 3D, rewards

## Problem

Visitors who want more than a quick check have nowhere to go: the rank C gate is deliberately light.

## Change

Build a second gate, rank S: full gameplay, extended 3D elements and a reward model, on the same record and agent
(epic decision 004), building on the visitor's shared progress (decision 006). Its card in `/gates` is unsealed.

## Done when

- `/gates/<its name>` opens the gate, and the catalog shows it as open.
- Progress earned in the rank C gate is visible and counts here.
- The rank C gate's load time is unchanged by this gate.

Planned in detail later: its own grilling settles the gameplay, the rewards and the 3D scope.
