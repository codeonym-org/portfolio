# 003: Beyond the record, the agent answers from an interview file the owner writes

**Date:** 2026-11-13 (grilling, Q3; agreed: "yeah, 2, and will be git tracked, so we can always do the grilling
session for common questions and update it regularly!")

**Question:** an HR interview asks things the record does not hold (motivation, weaknesses, salary, start date,
relocation). What does the agent answer?

**Decision:** **a new part of the record holds the owner's own answers to common HR questions, in his words.** The
agent answers from it in the first person.

- The file is tracked in git, next to the rest of the record. It is filled and refreshed by grilling sessions with
  the owner: the agent drafts the questions, the owner gives the answers.
- The agent still never invents an answer the file and the record do not hold.
- It never agrees to anything binding: a salary figure the owner did not write, an interview slot, an offer. For
  those it says the real Ayoub must confirm, and shows the contact card.

- **Why:** it is the only option where "the agent has all info on me" is true, and every answer is one the owner
  gave.
- **Not chosen:** record only (half of an HR interview is deflected); improvising in the owner's character (puts
  words in his mouth in front of recruiters).
