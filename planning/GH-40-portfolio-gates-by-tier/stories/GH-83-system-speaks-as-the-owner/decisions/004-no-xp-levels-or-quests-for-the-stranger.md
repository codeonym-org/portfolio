# 004: The stranger has no XP, levels, quests or sync percentage

**Date:** 2026-11-13 (grilling, Q4; agreed: "yeah, drop them!")

**Question:** the visitor earns XP and levels from six quests, and a sync percentage. What happens to that?

**Decision:** **all of it is removed from view.** The site still remembers what the stranger has opened, only so the
agent knows what they have not seen yet and can suggest it.

- **Replaces epic decision 006** (one shared progress): there is no progress to share. What stays shared between
  gates is the memory of what was seen.
- **Why:** nobody levels up while interviewing a candidate.
- **Not chosen:** one quiet "4 of 6 seen" marker; the same progress with plain wording.
