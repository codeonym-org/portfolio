# 005: Project write-ups restate each repository's README and add nothing beyond it

**Date:** 2026-11-12 (grilling, Q5; agreed: chose "From each README (Recommended)")

**Question:** where do the summary, detail points, stack list and links of the eight new projects come from?

**Decision:** **each repository's README**, restated in the record's voice. Nothing is stated that the README does
not say. Each entry links to its repository, and to its docs page where one exists. The owner reviews all eight
texts in the ticket before they are merged.

- **Why:** the agent may only state what the record shows, so the record itself must be checkable against a public
  source; the story does not wait on new text from the owner.
- **Not chosen:** README plus the owner's notes per project (richer, but the story waits on them); CV one-liners
  only (the agent has little to say about a project).
