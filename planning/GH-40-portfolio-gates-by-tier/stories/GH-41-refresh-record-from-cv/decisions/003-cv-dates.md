# 003: Project dates come from the owner's CV, shown as "since"

**Date:** 2026-11-12 (grilling, Q3; agreed: chose "CV dates (Recommended)")

**Question:** the CV and GitHub disagree on when projects started (CV: gsm-agent-kit 09/2026, Mediary 08/2026,
GroundWork 07/2026; repositories created 2026-10-14, 2026-09-26, 2026-10-23). Which dates does the record show?

**Decision:** **the CV dates**, shown as "since <month year>". For a project that is not on the CV, the agent
proposes a date and the owner corrects it before it is written.

- **Why:** work starts before a repository is published, and the record must match the CV a recruiter downloads.
- **Not chosen:** repository creation dates (verifiable, but projects look younger than they are and the record
  contradicts the CV); no start dates (the timeline of the work is lost).
